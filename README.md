# Ejercicios de C# - Arrays y Listas

## Descripción
Este proyecto contiene 3 ejercicios prácticos para aprender sobre **Arrays**, **Listas** y **Bucles** en C#.

## Ejercicios

### 1. 🌡️ El Profesor Perezoso (Arrays)
**Objetivo:** Calcular el promedio de temperaturas

Debes:
- Crear un array de `double` con 5 temperaturas
- Llenar el array con valores inventados
- Usar un bucle `for` para calcular el promedio
- Retornar el promedio

### 2. 🛒 Lista de Supermercado (Listas)
**Objetivo:** Crear una lista de compras interactiva

Debes:
- Crear una `List<string>` para guardar productos
- Pedir productos al usuario con un bucle `while`
- Terminar cuando el usuario escriba "salir"
- Mostrar la lista completa con `foreach`

### 3. 🔍 El Buscador (Reto)
**Objetivo:** Buscar un número en un array aleatorio

Debes:
- Generar 10 números aleatorios en un array
- Pedir al usuario qué número buscar
- Recorrer el array y decir si está o no
- Retornar `true` si lo encuentra, `false` si no
